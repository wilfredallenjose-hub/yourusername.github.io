
# Task 5: Deploy a Static Website Using GitHub Pages

## Objective
To host a static website for free using GitHub Pages.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages

## Project Description
This project is a responsive personal portfolio website.
It contains Home, About, Skills, and Contact sections.

## Deployment
1. Created a public GitHub repository.
2. Uploaded the website files.
3. Enabled GitHub Pages in repository Settings.
4. Selected the main branch and root folder.
5. Tested the deployed website.
